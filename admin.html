How to upload (step by step)
  1. Click Generate registry.js — the file combines the current registry with your new record. A repeated ID replaces the old record instead of duplicating it.
  2. Click Download registry.js.
  3. Open the repository on GitHub → Add file → Upload files.
  4. Drag the downloaded registry.js in, then click Commit changes.
  5. Wait 2–10 minutes. The credential is now verifiable at verify.iiefinstitute.org.
  6. To publish only real records, check Start a fresh registry before generating.
